# Templates

Reference templates for NMT migrations (DMDD, DQR, `.def` files, value mappings, etc.).

## Contents

- `dmdd_template.yaml` — Data Migration Design Document template (YAML, machine-readable)
- `dqr_template.yaml` — Data Quality Review template (YAML, machine-readable)
- `profile_report_template.md` — Source data profiling report template (Markdown)
- `DMDD_HH_v1.1.xlsx` — Reference DMDD spreadsheet (human-readable companion)
